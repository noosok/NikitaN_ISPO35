git clone - клонирует удаленный репозиторий
git status - показывает статус проекта (файлы)
git add - добавляет файл
git commit - делает коммит в ветку
git push - отправляет изменения в ветку
git log - выводит историю коммитов
git pull - синхронизирует изменения в ветке
git merge - объединяет изменения из указанной ветки с текущей
git branch - позволяет создавать, просматривать, переименовывать и удалять ветки
git init - инициализирует новый репозиторий Git в текущей директории
