Что такое Git и для чего он используется?
- это язык, который используется на github для управления файлами, версиями и для работы в команде.

В чём разница между централизованными и распределёнными системами контроля версий?
- централизованная версия - это главная версия проекта, копию которуй разработчики смогут взять для работы
- распределенная система - это локальная версия проекта, которая есть у каждого разработчика
Что такое репозиторий в Git?
- репозиторий - это отдельный проект, в котором хранятся файлы и код проекта
